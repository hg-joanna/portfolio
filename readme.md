# Personal Portfolio

A personal portfolio website showcasing my projects, skills, experience, and certifications.

## Built With

- Next.js
- React
- JavaScript
- CSS

## Getting Started

Install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

Deployed with Vercel.
